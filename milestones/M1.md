# Milestone 1 — Laravel Setup + Full Frontend

## Goal
Set up the Laravel project and build the complete frontend with static seed data.
By the end of this milestone, the website must be fully functional and visually complete.

## Definition of Done
- [ ] Laravel project created and running locally
- [ ] Database migration done with 3 seed products
- [ ] All 4 public pages working with real data from DB
- [ ] Fully responsive on mobile and desktop
- [ ] All brand colors and fonts applied correctly

---

## Tasks (in order)

### 1. Laravel Setup
- Create new Laravel 11 project
- Install TailwindCSS via npm
- Install Alpine.js via CDN in layout
- Configure `.env` for local MySQL connection
- Set APP_NAME=alsbakh

### 2. Database
- Create migration for `products` table
- Run migration
- Create Product model with fillable fields
- Seed 3 sample products (see seed data below)

### 3. Routes (web.php)
```php
Route::get('/', [HomeController::class, 'index']);
Route::get('/products', [ProductController::class, 'index']);
Route::get('/products/{slug}', [ProductController::class, 'show']);
Route::get('/contact', fn() => view('contact'));
```

### 4. Controllers
- **HomeController:** fetch `is_featured = true` products → pass to view
- **ProductController@index:** fetch all products → pass to view
- **ProductController@show:** find by slug or 404 → pass to view

### 5. Layouts
**layouts/app.blade.php** must include:
- Google Fonts (Inter)
- TailwindCSS
- Alpine.js
- Navbar: Logo left | Links center (Home, Products, Contact) with Products dropdown | Mobile hamburger
- Footer: Logo + links + contact info + copyright
- WhatsApp floating button (bottom right)
- Sticky navbar with backdrop blur on scroll

### 6. Pages

#### Home (/)
Three sections only:
1. **Hero** — Full-width image, headline, subheadline, 2 CTA buttons (Browse Products → /products, Contact Us → /contact). Background image from Unsplash.
2. **Stats Bar** — Dark blue background (#0B2C5E), white text. 4 stats with count-up animation: 8+ Warehouses, 100+ Cities, 3,500+ Distributors, 3,000+ Products
3. **Featured Products** — Grid of featured products (cards with image, name, brand, "View Details" button → /products/{slug}). Section title + "View All Products" button at bottom.

#### Products (/products)
- Page title + subtitle
- Simple responsive grid (3 cols desktop, 2 tablet, 1 mobile)
- Each card: image, name, brand, origin, "View Details" button

#### Product Detail (/products/{slug})
- Breadcrumb: Home > Products > {name}
- Left (60%): Main image (large), below it 3-4 related products grid
- Right (40%): Name (H1), description, brand, origin, features list, "Request Quote" button (opens WhatsApp), "Download Catalog" button (disabled for now)
- Image hover zoom effect (CSS only)

#### Contact (/contact)
- Page title
- Two big buttons: WhatsApp (wa.me/966570619556) and Email (info@almubarmij.com)
- Company info: address, working hours, phone
- Embedded Google Maps iframe

## Design Rules
- Use brand colors: #0B2C5E (primary), #D4A017 (CTA buttons), #1E6FBF (hover)
- Font: Inter from Google Fonts
- Cards: rounded-2xl, shadow-lg, hover:shadow-2xl transition
- Buttons: rounded-full, px-6 py-3
- Animations: Alpine.js x-transition for dropdowns, CSS transitions for hover effects
- NO custom .css files — TailwindCSS utility classes only
