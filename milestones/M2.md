# Milestone 2 — Admin Dashboard (Products CRUD)

## Goal
Build a fully functional admin dashboard to manage products.
Admin can login, view all products, add new ones, edit existing ones, and delete them.

## Prerequisites
- M1 must be 100% complete
- Products table already exists in database
- Laravel project running locally

## Definition of Done
- [ ] Admin can login with username + password
- [ ] Admin can see all products in a table
- [ ] Admin can add a new product with image URL
- [ ] Admin can edit any product
- [ ] Admin can delete any product (with confirmation)
- [ ] All admin routes are protected (redirect to login if not authenticated)
- [ ] Admin dashboard is separate from public website visually

---

## Tasks (in order)

### 1. Admin Authentication
- Use Laravel's built-in Auth (session-based, not JWT — simpler for Blade)
- Create admin user via seeder:
  ```php
  User::create([
    'name' => 'Admin',
    'email' => 'admin@alsbakh.com',
    'password' => bcrypt('alsbakh2024'),
  ]);
  ```
- Login page: email + password form, submit → redirect to /admin/products
- Logout button in admin navbar

### 2. Admin Routes (web.php)
```php
// Auth routes
Route::get('/admin/login', [Admin\AuthController::class, 'showLogin']);
Route::post('/admin/login', [Admin\AuthController::class, 'login']);
Route::post('/admin/logout', [Admin\AuthController::class, 'logout']);

// Protected admin routes
Route::prefix('admin')->middleware('auth')->group(function () {
    Route::get('/products', [Admin\ProductController::class, 'index']);
    Route::get('/products/create', [Admin\ProductController::class, 'create']);
    Route::post('/products', [Admin\ProductController::class, 'store']);
    Route::get('/products/{id}/edit', [Admin\ProductController::class, 'edit']);
    Route::put('/products/{id}', [Admin\ProductController::class, 'update']);
    Route::delete('/products/{id}', [Admin\ProductController::class, 'destroy']);
});
```

### 3. Admin Layout (layouts/admin.blade.php)
- Dark sidebar: links to Products
- Top bar: "alsbakh Admin" title + logout button
- Main content area
- Colors: sidebar #0B2C5E, accent #D4A017
- Separate from public app.blade.php

### 4. Admin Views

#### admin/login.blade.php
- Centered card
- Email + Password fields
- Login button (gold)
- Error message if wrong credentials

#### admin/products/index.blade.php
- Page title "Products" + "Add New Product" button (top right)
- Table columns: Image (thumbnail 60px) | Name | Brand | Origin | Featured | Actions
- Actions: Edit button + Delete button (with JS confirm dialog)
- Delete uses a small form with method spoofing (@method('DELETE'))

#### admin/products/create.blade.php
- Form fields:
  - Name (text, required)
  - Description (textarea)
  - Image URL (text, required) + preview below field when URL is entered
  - Brand (text)
  - Origin (text)
  - Slug (auto-generated from name via Alpine.js, editable)
  - Is Featured (checkbox/toggle)
- Submit button "Add Product" (gold)
- Cancel link back to products list

#### admin/products/edit.blade.php
- Same form as create, pre-filled with existing data
- Submit button "Update Product"
- Delete button (red, with confirmation) at bottom

### 5. Slug Auto-Generation
In create form, use Alpine.js to auto-generate slug from name:
```javascript
// when name changes, generate slug
slug = name.toLowerCase().replace(/\s+/g, '-').replace(/[^a-z0-9-]/g, '')
```

### 6. Image URL Preview
In create/edit form, show live image preview:
```html
<input x-model="imageUrl" type="text" placeholder="https://...">
<img x-show="imageUrl" :src="imageUrl" class="mt-2 h-32 rounded-lg object-cover">
```

### 7. Validation (in ProductController)
```php
$request->validate([
  'name' => 'required|string|max:255',
  'image_url' => 'required|url',
  'slug' => 'required|unique:products,slug',
  'brand' => 'nullable|string|max:100',
  'origin' => 'nullable|string|max:100',
]);
```

## Design Rules
- Admin uses same TailwindCSS
- Sidebar: bg-[#0B2C5E] text-white
- Buttons: Add/Save = bg-[#D4A017], Delete = bg-red-600, Cancel = bg-gray-200
- Table: alternating row colors (white/gray-50)
- Form inputs: border, rounded-lg, focus:ring-[#0B2C5E]
- Mobile responsive admin is NOT required (admin is desktop only)
