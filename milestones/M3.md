# Milestone 3 — Deploy to Hostinger

## Goal
Deploy the complete alsbakh website (frontend + admin) to Hostinger Shared Hosting.
The site must be live and accessible at bmatchdesgin.com.

## Prerequisites
- M1 complete: all public pages work
- M2 complete: admin dashboard works with full CRUD
- Hostinger account active with domain connected

## Definition of Done
- [ ] Website live at bmatchdesgin.com
- [ ] Admin dashboard accessible at bmatchdesgin.com/admin/login
- [ ] All products show correctly
- [ ] Admin can login and manage products from live site
- [ ] No errors in production

---

## Tasks (in order)

### 1. Prepare Laravel for Production

#### Update .env for production
```env
APP_ENV=production
APP_DEBUG=false
APP_URL=https://bmatchdesgin.com

DB_CONNECTION=mysql
DB_HOST=localhost
DB_PORT=3306
DB_DATABASE=your_hostinger_db_name
DB_USERNAME=your_hostinger_db_user
DB_PASSWORD=your_hostinger_db_password
```

#### Run production commands locally
```bash
composer install --optimize-autoloader --no-dev
php artisan config:cache
php artisan route:cache
php artisan view:cache
npm run build
```

### 2. Create Database on Hostinger
- Login to Hostinger hPanel
- Go to Databases → MySQL Databases
- Create new database: `alsbakh_db`
- Create database user + assign to database
- Note the credentials → update .env

### 3. Upload Files to Hostinger

**Important:** Laravel's entry point is `/public/index.php`
Hostinger serves from `public_html/`

**Two options:**

**Option A — Upload everything to public_html (simplest):**
```
Upload ALL Laravel files to public_html/
Then move contents of public_html/public/ to public_html/
Edit public_html/index.php:
  Change: require __DIR__.'/../vendor/autoload.php';
  To:     require __DIR__.'/vendor/autoload.php';
  Change: $app = require_once __DIR__.'/../bootstrap/app.php';
  To:     $app = require_once __DIR__.'/bootstrap/app.php';
```

**Option B — Keep structure clean (recommended):**
```
Upload Laravel project to: /home/user/alsbakh/
Create symlink or configure public_html to point to alsbakh/public/
```
Use Option A for Hostinger shared hosting — it's simpler.

### 4. Set Up Database on Hostinger
- Access phpMyAdmin from hPanel
- Import your local database OR run migrations remotely

**To run migrations via SSH (if Hostinger SSH is enabled):**
```bash
ssh user@your-server.hostinger.com
cd public_html
php artisan migrate --force
php artisan db:seed --class=AdminSeeder
```

**To import via phpMyAdmin:**
- Local: `php artisan migrate` + `php artisan db:seed`
- Export database from local phpMyAdmin (SQL file)
- Import SQL file into Hostinger phpMyAdmin

### 5. Set File Permissions
```bash
chmod -R 755 storage/
chmod -R 755 bootstrap/cache/
```

### 6. Configure .htaccess
Make sure public_html has correct .htaccess:
```apache
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteRule ^(.*)$ public/$1 [L]
</IfModule>
```
(Only needed if using Option B structure)

### 7. Test Everything

## Common Hostinger Issues & Fixes

| Issue | Fix |
|---|---|
| 500 Error | Check storage/ permissions + .env APP_DEBUG=true temporarily |
| Blank page | Check error log in hPanel → Logs |
| DB connection failed | Verify DB credentials in .env |
| CSS not loading | Run `npm run build` and re-upload public/build/ |
| Routes not working | Check .htaccess exists in public_html |
